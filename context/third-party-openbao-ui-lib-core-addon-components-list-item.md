# Context: third-party-openbao-ui-lib-core-addon-components-list-item

Repository: `deno-kcp`

These files exist as reusable building blocks for rendering a list item's content region and its popup menu inside the OpenBao UI. content.js is the tagless wrapper that keeps list item markup free of an extra element, and popup-menu.js is the tagless menu region that binds the list item it belongs to (item) and whether a menu should be shown (hasMenu), with its markup supplied by an external template. The context exists so the tagless-component contract and the popup menu's public properties and layout binding are stated explicitly for anyone consuming or modifying the list-item component family.
