# Context: third-party-openbao-github-issue-template

Repository: `deno-kcp`

This context exists to record the vendored GitHub issue-template metadata that deno-kcp carries for the OpenBao third-party tree. It is declarative configuration, not code: the three YAML files shape how contributors file documentation/ecosystem reports and RFC proposals against the upstream project, and config.yml decides which contact links the issue chooser offers. The context is documented so that its contents are known to be upstream-owned metadata with no Go build surface, letting future changes be treated as upstream syncs rather than local behaviour changes.
