Before spawning, it sets PDS_STATE_PATH and REPO_PRIVATE_KEY_HEX_PATH in the child environment to absolute paths in the pod's run directory, so the bidder's Deno.Kv state and key file are written where the pod may write instead of under a HOME the pod does not control."
